# Seedance Studio

3D-аниматики для Seedance без Blender. Собираешь место и героев по фото, двигаешь их мышкой, ставишь камеру как в игре и одной кнопкой получаешь MP4. Seedance принимает его как видео-референс `@ref1` и повторяет камеру один в один.

Бесплатный инструмент [AI Igonin](https://aiigonin.ru) · Instagram и Telegram @vladimiruss.

## Как начать

Открой новый чат на claude.ai и отправь:

> Подключи github.com/vladimirussfleet/seedance-studio, прочитай CLAUDE.md и открой мне студию

Claude создаст страницу «Seedance Studio» в твоём аккаунте. Открывай её в Google Chrome на компьютере. Подробный гайд с картинками приходит по слову СТУДИЯ в директ @vladimiruss.

## Что внутри

- Страница-редактор: 3D-вид, окно камеры, таймлайн с ключами и планами, запись MP4 прямо в браузере.
- Герои по фото: 3D-манекен с ростом, телосложением и цветами одежды. Сам ходит и бегает, умеет сидеть, махать, показывать.
- Своя 3D-модель: файл `.glb` из любого генератора 3D, с анимациями.
- Место по фото: серый макет и фото поверх кадра, чтобы повторить ракурс.
- Локальная версия для Claude Code и Codex: `SKILL.md`.
