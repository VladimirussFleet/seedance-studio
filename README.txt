SEEDANCE STUDIO — 3D-аниматики для Seedance без Blender
=========================================================

Что это
  Редактор в браузере + скилл для Claude Code / Codex. Собираешь героев и место по фото,
  расставляешь сцену, двигаешь героев и камеру по таймлайну и записываешь чистый MP4,
  который загружается в Seedance как видео-референс @ref1.
  Всё работает у тебя на компьютере: без подписок, без облака, проекты лежат в обычной папке.

Что нужно
  Mac (или Windows), Google Chrome, Node.js 20+, ffmpeg.
  Mac:  brew install node ffmpeg

Установка (5 минут)
  1. Распакуй папку seedance-studio в  ~/.claude/skills/seedance-studio/
     (для Codex:  ~/.agents/skills/seedance-studio/). SKILL.md должен лежать прямо в ней.
  2. В терминале:
       cd ~/.claude/skills/seedance-studio/studio
       npm install
  3. Перезапусти Claude Code.

  Проще: открой Claude Code в любой папке, перетащи зип и напиши:
       «Установи этот скилл»

Как пользоваться
  С агентом:
     открой Claude Code в папке для роликов и напиши, например:
     «Используй seedance-studio. Вот фото героев и фото места. Сцена: …(описание или промпт Seedance)…»
     Агент соберёт сцену, покажет раскадровку и откроет редактор.

  Сам, без агента:
       node ~/.claude/skills/seedance-studio/studio/server.mjs
     Откроется http://localhost:5178. Проекты сохраняются в ./projects рядом.

Редактор: главное
  • Слева «Добавить»: человек, машина, кубы, стены, 3D-модель (.glb).
  • Клик по объекту — выбрать. Стрелки гизмо — двигать (W), дуги — вращать (E).
  • Правая кнопка мыши / два пальца — вращать вид, колесо — приблизить, F — к объекту.
  • Анимация: поставь время на таймлайне и сдвинь героя — появится ключ (◆ Авто-ключ).
    Ключи на таймлайне можно перетаскивать.
  • Камера: найди ракурс в рабочем виде → «📷 Ключ камеры из вида» (K).
    Два ключа в одном плане = проезд камеры. «✂ Разрезать план» = склейка.
  • C — смотреть через камеру. Фото места ложится поверх кадра, чтобы повторить ракурс.
  • «⏺ Записать для Seedance» — чистый MP4 для @ref1. «С подписями» — для проверки.
  • Cmd+Z — отмена. Всё сохраняется само.

Герои по фото
  • 3D-манекен: рост, телосложение, цвета кожи, волос и одежды, причёска — по фото.
    Сам идёт и бежит по скорости, позы: сидит, машет, показывает, руки вверх, лежит.
  • Своя 3D-модель: .glb из любого генератора 3D. Перетащи файл во вьюпорт.
    Анимации внутри модели проигрываются.
